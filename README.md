本版门店展示：恢复固定每9秒轮播3家普通门店，梅河店固定第4行。新单或已发生订单金额更正时，最近变动门店临时提到最上方，其他变动门店优先跟随；到下一次正常轮播恢复金额降序窗口。旋转时刻碰上新单则保留其置顶，防止马上被挤出。轮播只切换展示，不增加金额；真实金额继续与流水、门店合计及今日销售额同步。重复通知不重新启动收入光效，旧浏览器间隔设置不覆盖固定9秒。11、12月计划卡片文字和描边适度提亮，仍弱于当月卡片。

本版时间口径：每天自动复用10月5日、6日的1682张订单和5068条明细，把X列日期映射为当天；整单Z列处理时间与明细Y列销售时间分别保留。打开页面立即计算当前北京时间之前的整单K金额，新单到时联动收入；每日不用重新导出。同日刷新不重复计入，跨日从当日基数及新日已发生时刻重算。修复决策引擎借用主单Z作为明细时间的问题，商品数量时段改用Y，整单收入及订单高峰仍用Z。

本版修复：自动计时先于可选图表注册，每秒核对发生时刻；多标签页接收进度不再反复写回造成循环重绘。重新打开时默认显示当天订单，历史预览不会锁住主屏。今日流水按发生时刻降序保留最新3笔，新单从顶部插入、旧行下移，取消5分钟清空限制；已有订单不再循环成“新订单”。每秒按北京时间更新截止数据，新订单到时同步更新今日销售额、对应门店金额/排名及门店合计。流水入场与合计闪光、柱内流光对应同一批订单变化。退款扣减，同秒多笔一次汇总；页面刷新按当前时刻重算，不重新累计旧单。没有新单时金额保持不变。

智慧决策隐藏“查看依据”，将泛泛观察改为订单贡献、客单对比、商品集中度、近期订单节奏等具体判断和对应动作。内部证据和核验仍保留；60秒刷新，也响应订单数据变更。当前采用事实规则，未配置远端AI服务时不宣称已调用大模型。
